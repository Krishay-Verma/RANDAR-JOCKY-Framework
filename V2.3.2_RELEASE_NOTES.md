# RANDAR V2.3.2 — UI readability and brand polish

## User-visible changes

- Replaced the letter-based mark with an original shield + compass-radar symbol in the existing green palette; updated the app icon and favicon together.
- Reworked sign-in into a responsive two-column layout with clear hierarchy, better spacing, accessible form labels, visible token guidance, and server-verification context.
- Increased baseline typography and improved table, navigation, form-control, and panel readability.
- Reduced excessive micro-label styling and added safer wrapping so long evidence strings and headings do not protrude from their containers.
- Kept RANDAR's existing charcoal, green, white, and cool-grey visual identity. The security-product inspiration is limited to a clean, structured enterprise layout; no other brand assets are copied.

## Scope

This is a frontend presentation update. It does not change authentication semantics, API behavior, forensic collection, runtime limits, or evidence processing.

## Validation

- SVG files parsed as XML.
- Frontend source and package metadata inspected for the new sign-in component and release identity.
- A production Vite build should be run in an environment with frontend dependencies installed; this environment may not have a complete node_modules directory.
