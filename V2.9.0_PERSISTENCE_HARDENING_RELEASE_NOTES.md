# RANDAR V2.9.0 — Persistence Forensic Hardening Notes

## Release status

This is the hardened V2.9.0 source baseline for Windows endpoint persistence forensics.

## Verified

- 29 collectors registered.
- 57 analysis rules registered.
- 162 Python regression tests passed.
- `python -m compileall -q jocky` passed.
- Clean Windows persistence fixture: fewer than 15 findings and no high/critical findings.
- Planted persistence fixture: Run key, Temp scheduled task, unsigned writable service, and WMI subscription all surface as distinct investigative leads.

## Primary fixes

1. DACL-aware service write checks with `unknown` when ACL inspection is unavailable.
2. General semantic deduplication of duplicate rule families.
3. Windows environment-variable expansion and canonical path comparison.
4. Startup filtering and `.lnk` resolution.
5. Multi-signal scheduled-task and startup scoring.
6. Executable verification and trusted-publisher enrichment.
7. Bounded context enrichment for persistence leads: parent directory, task registry cache, related processes and network connections.
8. Stable finding IDs and collector evidence references.
9. Mandatory limitations and next-check fields with schema validation.
10. Timeline construction from persistence, process and Windows-event timestamps.
11. Script/compilation provenance and independent evidence-hash verification.
12. Elevation and collector coverage/confidence reporting.
13. Explicit Sysmon `not_installed` state.
14. Correct Windows Event Log truncation/no-match/access semantics.
15. Top-level finding summary and risk-ranked leads.
16. Expanded persistence coverage: WMI, IFEO, Winlogon, AppInit, COM, BITS, all-user Startup, browser extensions, Office add-ins, LSA authentication packages and service configuration anomalies.

## Safety boundary

RANDAR remains a read-only forensic scanner. These additions inventory and analyze persistence artifacts; they do not create, modify, enable, disable, or execute persistence mechanisms.

## Build limitation

The Python/backend test suite is verified in this environment. A production Vite build was not reproduced because the environment lacks the Vite dependency and package retrieval is unavailable.
