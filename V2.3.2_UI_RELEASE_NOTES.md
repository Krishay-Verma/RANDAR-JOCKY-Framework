# RANDAR V2.3.2 — UI Readability & Brand Refinement

## Scope
V2.3.2 is a presentation-focused patch on V2.3.1. It does not alter the forensic runtime, collection, evidence, authentication, or JOCKY execution semantics.

## UI changes
- Reworked global typography toward a human-readable system sans stack with clearer size and line-height hierarchy.
- Increased navigation and header spacing so labels no longer feel cramped or visually clipped.
- Improved form controls, table density, headings, and content spacing while retaining the existing RANDAR green/charcoal/white palette.
- Redesigned the sign-in screen as a responsive two-panel security-console layout with clearer alignment and stronger visual hierarchy.
- Kept the sign-in copy focused on local forensic-console access and the existing API-token workflow.
- Replaced the previous J-shaped icon with a dedicated RANDAR compass/radar mark.
- Updated the favicon to the same compass/radar mark.

## Brand direction
The visual language takes general inspiration from established security-software consoles: restrained green accents, dark charcoal surfaces, strong grid alignment, and a clear security-oriented emblem. It does not copy another vendor's logo or proprietary artwork.

## Validation
- RANDAR and JOCKY backend source remains unchanged by this UI-only patch.
- SVG assets parse successfully.
- CSS brace balance validated.
- Frontend production build was not run because the environment's `npm ci` operation timed out before Vite became available.
