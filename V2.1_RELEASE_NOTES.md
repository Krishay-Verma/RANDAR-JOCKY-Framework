# RANDAR / JOCKY V2.1.0 — Transformation & Build Identity

V2.1 extends the existing V2.0 compiler/IR/signed-bytecode path with a real,
semantics-preserving representation transformation pipeline and signed build
identity metadata.

## Implemented

- Transformation profiles:
  - `none`
  - `deterministic`
  - `randomized`
  - `reproducible-randomized`
  - `compatibility-preserving`
- JOCKY variable-identifier representation transformation for compiled IR.
- Transformation input/output hashes.
- Transformation ID derived from version, profile, seed and representation hashes.
- Signed build ID embedded in the bytecode header.
- Artifact SHA-256 calculated over the complete signed bytecode blob.
- Compiler API support for transformation profile and seed.
- `/api/bytecode/compile` support for V2.1 transformation controls and build identity.
- CLI support for `--transformation-profile` and `--transformation-seed`.
- Reproducibility tests and API coverage.

## Boundary

This release transforms JOCKY's own representation. It does not implement
native-binary packing, security-control bypass, process injection, kernel
subversion, or covert transport. Those are separate research concerns and
are not required for the V2.1 compiler/build-identity milestone.
