# RANDAR V2.6.0 — Persistence & Privilege Forensics

V2.6 adds a controlled, read-only persistence and privilege correlation track. It builds on existing startup-item, scheduled-task, service, account, session, process, Windows Event Log and Sysmon collectors.

## Implemented
- Dedicated `/api/persistence-forensics/scan` endpoint.
- `jocky persistence-scan` CLI command.
- Deterministic persistence/privilege snapshot identity.
- Cross-surface executable-path correlation across startup items, scheduled tasks and services.
- Privilege-event contextual correlation.
- Dedicated Persistence & Privilege Forensics console workspace.
- Investigation-detail persistence tab and findings integration.
- Investigation-list persistence capability summary.
- Two new JOCKY analysis rules: `persistence_cross_surface_correlation` and `persistence_privilege_correlation`.
- Regression coverage for deterministic identity, findings, routing and UI integration.
- Fixed an existing investigation-list bug where memory/driver record counts referenced an undefined `record` variable instead of the current row.

## Boundary
This release only observes metadata and telemetry. It does not create, modify, enable, disable, or execute persistence mechanisms and does not change privilege state.
