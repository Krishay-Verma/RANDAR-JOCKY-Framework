# RANDAR V2.7.0 — Investigation navigation & cross-surface correlation

V2.7 fixes the investigation navigation gap where Memory Forensics and Driver Forensics were present in source but could be hidden beyond the tab row or were difficult to reach from the investigations list. It also adds a read-only cross-surface correlation view.

## Implemented
- Investigation detail tabs now wrap instead of clipping or relying on horizontal overflow.
- Persistent, always-visible forensic workspace shortcuts for Memory Forensics, Driver Forensics, and Persistence & Privilege.
- Direct investigation pivots from the Investigations list to `?tab=memory`, `?tab=driver`, and `?tab=persistence`.
- Query-parameter tab routing validates allowed tabs and preserves the case context.
- New Cross-Surface Correlation tab groups findings by supporting evidence collectors without inferring causality or a malware verdict.
- Correlation metrics for finding count, evidence surfaces, high/critical findings, and review indicators.
- Investigation-list Forensics column gives direct access to specialized workspaces.
- Existing Memory, Driver, and Persistence tabs remain fully functional.

## Boundary
The correlation view is read-only presentation of stored investigation evidence. It does not execute processes, alter kernel state, modify persistence, or assign an automatic malware verdict.
