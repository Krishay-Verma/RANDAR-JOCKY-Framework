# RANDAR V2.3.3 — PE certificate parser warning cleanup

V2.3.3 is a focused maintenance patch following the V2.3.2 UI release.

## Fixed

- Suppressed the expected `cryptography` UserWarning emitted when an Authenticode PKCS#7 certificate payload is BER-encoded and the library falls back from DER parsing.
- Preserved the existing certificate recovery behavior and forensic result fields.
- Added a regression test to ensure the warning does not pollute the RANDAR operator console.
- Updated frontend/toolchain and current-state version metadata to `2.3.3`.
