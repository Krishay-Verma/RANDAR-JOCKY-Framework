# RANDAR / JOCKY V2.0.0 Release Notes

## Scope

V2.0 completes the first roadmap stage: formalizing the JOCKY language and
turning the existing lexer/parser/IR/interpreter/bytecode stack into an explicit
cross-platform compiler and toolchain for Windows and Ubuntu.

## Implemented

- Formal machine-readable JOCKY V2.0 grammar/specification.
- Public source compiler facade.
- Canonical IR representation and stable IR hashing.
- Source hashing for artifact provenance.
- Explicit `portable`, `windows`, and `ubuntu` targets.
- V2.0 compiler/IR/target metadata in signed bytecode.
- Deterministic/reproducible compilation mode.
- Runtime target compatibility checks.
- `jocky compile`.
- `jocky validate`.
- `jocky verify`.
- `jocky inspect`.
- `jocky sign`.
- `jocky run`.
- `jocky spec`.
- API support for target and deterministic compilation metadata.
- Regression and V2.0 test coverage.

## Compatibility decision

The existing signed bytecode wire format remains at bytecode `version = 1`.
V2.0 is the language/toolchain release and adds V2 metadata without breaking
existing API consumers or previously validated bytecode artifacts.

## Validation

Final local test suite:

```text
103 passed
```

The deterministic compiler was also exercised twice against the same source,
target and signing key; the generated artifacts were byte-for-byte identical.

## Out of scope for V2.0

The later roadmap versions cover transformation research, execution research,
in-memory forensic analysis, driver/BYOVD detection, persistence/privilege
forensics, network routing, cloud transport and the integrated research
platform. V2.0 deliberately establishes the compiler/toolchain foundation
first.
