# RANDAR V2.9.0 Release Notes

## Focus

V2.9.0 adds defensive software-context classification and strengthens long-running investigation execution.

### Software context flags

Collected process, module and driver evidence can now be annotated with product/category flags for common endpoint-security, EDR, anti-cheat, VPN and virtualization software.

The classifier is evidence-first:

- Product flags come from stable process names, service names and path tokens.
- `KERNEL DRIVER` is shown for actual driver-inventory records.
- `KERNEL COMPONENT` is shown on a process only when a matching driver record was observed in the same evidence set.
- Product classification is contextual evidence and is not a malware verdict.

The live catalog exposes the software profiles so the UI can display current capability coverage.

### Long-running investigation flow

Injection / PE and Windows Telemetry sidebar hunts now use the same background investigation job model already used by New Investigation and the standalone forensic workspaces. Route changes therefore stop polling only; they do not cancel the server-side operation.

### Timeout policy

The bounded collector policy now gives slower Windows surfaces more appropriate ceilings while retaining the 600-second overall investigation runtime bound.

### JOCKY capability synchronization

`memory_forensics_correlation` is now a registered analysis rule and is available to the Memory Forensics and Domain Expansion templates.

## Safety boundary

V2.9.0 remains read-only. It does not add driver exploitation, process injection, anti-cheat bypass, EDR disabling, kernel modification or security-control evasion.
