# RANDAR / JOCKY V2.2.0 — Automated Transformation Research Pipeline

V2.2 extends the V2.1 representation transformation boundary into a controlled, measurable research pipeline. It operates on JOCKY IR/bytecode representation only.

## Implemented

- `automated-obfuscation` transformation profile.
- Automated composition of identifier representation changes and serialized-layout diversification.
- Representation-only provenance tags.
- Semantic-equivalence validator that normalizes variable identifiers and ignores non-semantic metadata.
- Transformation experiment model with experiment ID, source/IR hashes, input/output artifact hashes, compiler version, transformation ID, validation status, and timestamp.
- SQLite persistence for transformation experiments.
- Authenticated API endpoints for running experiments, listing experiment history, and retrieving experiment summary statistics.
- CLI `jocky experiment` workflow with optional JSON output.
- V2.2 metadata carried into signed bytecode headers.

## Research boundary

The V2.2 engine changes JOCKY representation only. It does not generate native-binary obfuscation, implement process injection/hollowing, alter kernel state, disable security controls, or provide covert transport.
